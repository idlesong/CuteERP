销售总览（首页 /）

顶部 FY 切换（上年 / 当前 / 下年财年）；三个视图按 tab 切换（tab 记忆：切换度量/FY 整页刷新后仍停留在原视图），均按客户条目判币别拆「人民币客户 / 美元客户(USD)」 分节显示，各自小计；金额带币别符号（¥/$），数量为纯数字：

  1. ① 实际出货：大类 → 客户矩阵，行尾并入 全年 Plan / 当月 Plan 对比 （取数：实际出货按分配台账加权价 × 当月汇率折 RMB）
  2. ② Plan (Budget)：货币段 → 大类 → 客户；数量 / 芯片 / 软件 / 总额 按钮组切换
  3. ③ 客户订单视图：与实际出货同版式（数量 / 芯片额 / 软件额 / 总额 按钮组）， 取当月接收的已提交订单行直接计价（含冲销负数，不依赖分配台账）， 按订单行价格快照拆 芯片额=base_price、软件额=v1+v2

客户订单（/orders）

  • 列表：按行显示（行编号 = 客户订单号-行号，如 PO123-2）；列筛选行 + 底部快速创建行； 日期列月份下拉、数值列 最小~最大 区间筛选；筛选/排序/页码记忆（stateSave，8 小时）
  • 快速创建：选客户 → 选型号（只显示该客户有报价的型号）→ 选价格（已批准价格按客户+型号过滤， 唯一价格自动选中）→ 数量（订单量档位与阶梯价目一致，选后自动显示 ODM/OEM 与参考阶梯价）； 后缀下拉（分解/签发用）取自系统设置 naming.suffixes
  • 订单号失焦预显：输入已有 PO 显示 PO123-3（追加到草稿单） 并自动带出客户
  • 状态：草稿（黄行，操作列可"提交"）/ 已提交（绿）/ 冲销（红）； 未签发的已提交单可随意修改；已被签发的单走冲销
  • 详情页：草稿与未签发的已提交单均可加行/删行/改单头；附件：客户 PO 原件 （PDF/图片，可多文件上传/删除）
  • 冲销（D1）：详情页"创建冲销单" → 按行录冲销数量（≤ 可冲销余额； 余额按「全部冲销行合计 ≤ 原行数量」口径，支持幂等重导）→ 生成 PO-R1 冲销单（数量为负）
  • 接收日期口径：列表按 created_at；导入时把文件接收日期写进 created_at， 重复导入以文件日期刷新；价格匹配以接收日期为基准（as-of，支持补录历史订单）
  • 币别（D9）：从客户快照，汇率按订单月快照；USD 客户订单行按美元价匹配

报价单（/quotations）

  • 报价号：QT+日期+3位流水（如 QT20260310-011），删除后流水不重用（安全删）
  • 快照明细：生成时复制价格成分到报价行（price_id 仅追溯），后续调价不影响已出的报价单； 同一价格可进多张报价单
  • 入口：价格详情页生成/关联；支持新建与编辑
  • PDF 输出：详情页打印/下载（自包含打印样式，中文系统字体栈）

六联单 / 生产订单（/sales_orders）

  • 签发：从客户订单行池（净需求 = 数量 − 冲销 − 已分配，DemandQuery 统一口径）选行， 输入后缀拼正式型号（组合不存在自动建档）+ 数量 + 版本 → 生成六联单； 工作台"分解"弹窗可对单行快捷签发；后缀集合 = 系统设置 naming.suffixes（默认 C/M/S）
  • 分配台账（D2）：六联单行 ↔ 客户订单行多对多（跨订单拆量、部分/全量、事后可调）； 分配引用支持 订单号-行号 或纯订单号（PO 内唯一行自动对应）
  • 状态：草稿（不占签发池）→ 提交（占池、可出库）→ 已出完（列表隐藏出库入口）； 未出库行可随意修改（型号/数量/版本/统一编号/备注），删行需求自动释放回待签发池； 已出库行数量只能增不能减
  • 单号：XS{yyyy}-{流水}，流水按年重置、固定 3 位（XS2026-005）
  • PDF：详情页可输出 invoice / packing list（与报价单同一套打印样式）
  • 出库：出库页按行拆量，可多次出库；发货时间 = 末次出库（派生）

出货（/shipments）

  • 出库单列表（月份筛选）+ 快速出库行：选六联单（显示核对信息）→ 可填总数量 （留空整单出完，按行顺序填充）
  • 工作台"快捷出货"弹窗：按行修改本次出库数量
  • 快递号在出库明细页可查（对账单为紧凑版式已省略附加列）

价格（/prices）

  • 报价行：客户 × 通用型号 × 订单量档位；成分拆分 芯片(base) + 声码1(v1) + 声码2(v2)， 三成分之和必须等于总单价（容差 0.01，吸收显示舍入）；快速创建支持公式（=50+50 自动拆分）
  • 状态机：requested（显式待审批，导入时状态列填 requested 保留）→ approved（生效）； active 为历史已批准状态，视同 approved；有效期内 + 已批准 = 生效， 有效期内未批准显示"批准"按钮；否则"失效"
  • 行内编辑：点"编辑"当行变输入行（同款交互见客户/产品列表）；编辑/批准后回到原筛选原页码
  • 顶部筛选：状态（全部/requested/approved）、PRR 标记——随 redirect 一并带回
  • USD 客户建价：换算助手 USD = RMB基准价 ÷ 1.13 ÷ 当月汇率，自动填充可改（只发生在建价一次）

阶梯价目（更多 → 阶梯价目）

  • 发布批次制：Excel 整表导入 = 新批次；最新批次可增补行（一次写 16 档，OEM/ODM × 8 数量档）
  • 签发与下单的参考阶梯价均取最新批次；历史批次只读可切换

工作台（右上角 @用户名）

  • 客户订单(待签发)：草稿行（可提交）+ 已提交未分配完的行（可分解/快捷签发）， 与客户订单列表同款交互（筛选 + 快速创建），不分页
  • 六联单(待发货)：草稿（可提交）+ 未全部发货的六联单（快捷出货弹窗可按行改数量）

月度对账（更多 → 月度对账）

页面 = 单客户对账 + 全客户内部对账（同一月份，客户下拉为中文名）：

  • 客户对账单（单客户视角）三段式：
    1. 订单核对段（当月接收的已提交订单行，含冲销负金额，按接收日期排序）
    2. 出货核对段（当月出库明细，单价来自分配台账加权价）
    3. 未交订单（截至月末：订单量 − 冲销 − 已出货） 金额双口径：本币 + 折 RMB（汇率取 exchange_rates 表当月值）；xlsx 导出
  • 全客户内部对账单（销售内部核对）：三段式跨全部客户合成， 排序 = 币别 → 客户名称 → 日期 → 单据号；按客户币别拆「人民币客户 / 美元客户(USD)」 分节显示、各自小计 + 段合计折 RMB（页面与导出同口径）； 金额按 芯片/声码1/声码2 成分拆分列示（出货段用分配加权价，与月度工作簿同公式； 出货币别 = 分配订单快照币别优先、客户现币别兜底）；汇率随行；三段表接列筛选 （客户列打字过滤、日期列月份下拉）；xlsx 导出
  • 对客户的正式对账单不拆成分（成分拆分为内部口径）

导出当月（更多 → 导出当月）

  • 月度工作簿（xlsx）7 张表：汇总 / 计划 / 出库单 / 价格 / 客户 / 产品 / 未交订单
  • 出库单表含 RMB 金额/成分销售额/声码器名称，成分列与导入模板同口径（可回导）
  • 统一口径：金额未税 = 含税 ÷ 1.13；当月统计按日界时间（不会漏边界小时单据）

导入（更多 → 导入，导入中心）

六类导入卡片：客户订单 / 价格 / 六联单 / 出库单 / 客户 / 产品。 均按表头名称解析（容忍列序变化、空列、多余统计列），与月度工作簿同模板：

导入器 自然键（幂等） 要点
客户订单 订单号+通用型号+版本 型号命名校验仅 Baseband 类别（9 位=通用 / 10 位=通用+后缀∈设置；RF 等类别通用型号=完整型号不校验）；含税单价自动匹配报价拆分成分（跨客户兜底报价/无报价未拆分给警告）；负数量或标注"冲销"→ 生成冲销单 PO-Rn（受可冲销余额限制）；接收日期落库 created_at，重导以文件日期刷新；版本可选
价格 Price_number 芯片必填、声码可缺省（缺省并入芯片；总单价为 =公式 时芯片豁免）；成分合计≠总价直接报错；状态空白/无法识别 → approved（requested 显式保留待审批）；同客户+型号+档位已有未过期价 → 仅警告，不自动替代（旧价失效人工处理；新价生效由匹配规则"生效日期最新"自然保证）
六联单 六联单号 导入即提交（D14，过渡期 Excel 为准）；分配对「订单N」支持纯订单号；「产品」列完整型号 → suffix 落行；分配直接建台账（Σ分配=数量校验）
出库单 六联单号|日期|快递号 同键多行合单、同产品累加；重复导入整单重建（幂等）；客户与六联单不符按六联单客户处理（警告）
客户 英文名（中文名唯一） 客户订单导入的前置；资料更新幂等
产品 通用型号（同文件唯一） 订单导入的前置；通用型号 = 型号原文（不再拆末位字母），后缀清空

两阶段导入（预检 → 修正 → 导入，导入永不带错落库）：

  1. 「检查」按钮：只跑预检——在回滚事务中完整执行导入器，不落任何数据； 结果分 errors（阻断：必填缺失/客户或型号未建档/命名规则不符/引用不存在/分配超余额等） 与 warnings（不阻断：跨客户兜底报价/同档位已有未过期价等），均带行号
  2. 标注文件：预检发现错误或警告时自动生成 xlsx （原表 + 末列「检查结果」逐行标注错误/警告，另有「全局问题」表）， 顶部横幅提供下载（30 分钟有效，token 跨刷新持续显示）；按标注修正后重新上传
  3. 「导入」按钮：先预检，有错误即阻止导入；导入完成后批次报告列出 新建/更新/跳过/错误/警告明细，底部批次历史可查

客户/产品是订单链路的前置，建议先「检查」通过再导订单。

关账与归档（更多 → 关账与归档）

  • 关账月单据锁定（不可改删）；重开留痕（重开人/时间）；关账自动归档 pg_dump 压缩包 + 当月工作簿到 storage/backups/
  • 恢复语义（D13）：灾难 = 整库恢复归档点；纠错 = 重开月份修单或冲销
  • 日常备份：每日自动（保留 30 天）

年度计划（更多 → 年度计划）

  • 财年止年标记（FY2027 = 2026-04 ~ 2027-03）；大类 × 客户 × 财年 12 月矩阵
  • 度量：数量 / 芯片额（base 口径）/ 软件额（v1+v2 口径）；币别按客户派生，汇总折 RMB
  • Plan.xlsx 导入：货币段（人民币/美元）→ 大类 → 客户行；各级合计行不导入（系统自动聚合）； 客户名匹配 英文名/全称/中文名，失败进校验报告

基础数据与设置

  • 客户（/customers）：英文名/中文名/全称/区域/销售类型(OEM/ODM)/代理商/币种(RMB|USD)/ 付款（默认款到发货）/发票三件套；行内编辑；支持导入（幂等更新）
  • 产品（/items）：通用型号 = 型号原文（不再拆末位字母），完整型号 = 通用型号 + 后缀 （后缀在六联单转产时定型）；base_item/extra_item/extra_item2 对应 芯片/声码1/声码2 组件； 类别（Baseband/RF 等，对齐 Plan 大类）——仅 Baseband 参与命名规则校验； 行内编辑；「谁买过」透视入口；支持导入（重导同型号自动归一）
  • 汇率设置（更多 → 汇率设置）：按月手工录入各币种汇率； 订单/六联单创建时快照当月值，报表按出货月取值折 RMB；缺失月份需先补录再导出报表
  • 系统设置（更多 → 系统设置）：账号管理；用户设置中维护 naming.suffixes （Baseband 第 10 位合法后缀集合，默认 C/M/S——签发后缀下拉与客户订单导入校验共用）

型号命名规则（Baseband，导入/签发共用）

完整型号 = SCT + 4位数字 + XY + [Z]
           └─ 前 9 位 = 通用型号 ─┘  └ 第 10 位 = 后缀（可缺省）
  • 按长度派生：9 位 = 通用型号（如 SCT3089MM 就是通用型号）；10 位 = 通用 + 1 位后缀 （如 SCT3089DVC → 通用 SCT3089DV + 后缀 C，后缀 ∈ 系统设置 naming.suffixes）
  • 长度不限制（通用型号有 7 位 SCT1234 与 9 位 SCT1234XY 两种形态）； Baseband 之外的类别（RF 等）通用型号 = 完整型号，不参与命名校验
  • 产品档案命中的型号优先用档案登记值（注册表优先）
