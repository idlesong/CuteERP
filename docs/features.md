## 客户订单（/orders）

- **列表**：按行显示（行编号 = 客户订单号-行号，如 `PO123-2`）；列筛选行 + 底部快速创建行
- **快速创建**：选客户 → 选型号（只显示该客户有报价的型号）→ 选价格（已批准价格按客户+型号过滤，
  唯一价格自动选中）→ 数量（订单量档位与阶梯价目一致，选后自动显示 ODM/OEM 与参考阶梯价）
- **订单号失焦预显**：输入已有 PO 显示"PO123-3（追加到草稿单）"并自动带出客户
- **状态**：草稿（黄行，操作列可"提交"）/ 已提交（绿）/ 冲销（红）
- **详情页**：草稿与未签发的已提交单均可加行/删行/改单头；已被签发的单走冲销
- **冲销**：详情页"创建冲销单"→ 按行录冲销数量（≤ 可冲销余额）→ 生成 `PO-R1` 冲销单

## 六联单 / 生产订单（/sales_orders）

- **签发**：从客户订单行池（净需求 = 数量 − 冲销 − 已分配）选行，输入后缀拼正式型号
  （不存在自动建档）+ 数量 + 版本 → 生成六联单；工作台"分解"弹窗可对单行快捷签发
- **状态**：草稿 → 提交（提交后才可出库）；未出库行可随意修改（型号/数量/版本/统一编号/备注），
  删除行需求自动释放回待签发池；已出库行数量只能增不能减
- **单号**：`XS{yyyy}-{流水}`，流水按年重置、固定 3 位（XS2026-005）
- **出库**：出库页按行拆量，可多次出库；发货时间 = 末次出库（派生）

## 出货（/shipments）

- 出库单列表 + 快速出库行：选六联单（显示核对信息）→ 可填总数量（留空整单出完，按行顺序填充）
- 工作台"快捷出货"弹窗：按行修改本次出库数量

## 价格（/prices）

- 报价行：客户 × 通用型号 × 订单量档位；成分拆分 芯片(base) + 声码1(v1) + 声码2(v2)，
  快速创建支持公式（`=50+50` 自动拆分）
- 生效逻辑：**有效期内 + 已批准 = 生效**；有效期内未批准显示"批准"按钮；否则"失效"
- 行内编辑：点"编辑"当行变输入行（同款交互见客户/产品列表）

## 阶梯价目（更多 → 阶梯价目）

- 发布批次制：Excel 整表导入 = 新批次；增补行一次写入 16 档（OEM/ODM × 8 数量档）
- 签发与下单的参考阶梯价均取**最新批次**

## 工作台（点击右上角用户名）

- **客户订单(待签发)**：草稿行（可提交）+ 已提交未分配完的行（可分解/快捷签发），
  与客户订单列表同款交互（筛选 + 快速创建），不分页
- **六联单(待发货)**：草稿（可提交）+ 未全部发货的六联单（快捷出货弹窗可按行改数量）

## 月度对账（更多 → 月度对账）

- 客户 × 月份对账单，三段式：
  1. **订单核对段**（当月接收订单行）2. **出货核对段**（当月出库明细）
  3. **未交订单**（截至月末：订单量 − 冲销 − 已出货）
- 金额双口径：本币 + 折 RMB（汇率取 exchange_rates 表当月值）；CSV 导出
- 对账对象（内部）另见导出工作簿的成分拆分（不对客户展示）

## 导出当月 / 导入（过渡期 Excel 双轨）

- **导出当月**：月度工作簿 7 张表 —— 客户订单（含未税/成分拆分/未交订单）、六联单（含分配对）、
  出库单（含 RMB 金额/成分销售额/声码器名称）、价格、阶梯、客户、产品
- **导入**：客户订单（自然键 订单号+通用型号+版本 幂等）、六联单（含分配对直接入台账，D14），
  每次导入出校验报告并记录批次

## 关账与归档（更多 → 关账与归档）

- 关账月单据锁定（不可改删）；重开留痕（重开人/时间）；关账自动归档
  pg_dump 压缩包 + 当月工作簿到 `storage/backups/`
- 恢复语义（D13）：灾难 = 整库恢复归档点；纠错 = 重开月份修单或冲销

## 年度计划（更多 → 年度计划）

- 财年止年标记（FY2027 = 2026-04 ~ 2027-03）；大类 × 客户 × 财年 12 月矩阵；
  Plan.xlsx 导入（货币段 → 大类 → 客户行，未匹配进报告）

## 基础数据与设置

- **客户**：英文名/中文名/全称/区域/销售类型(OEM/ODM)/代理商/币种/付款（默认款到发货）；
  行内编辑
- **产品**：型号 = 通用型号 + 后缀（软件段）；base_item/extra_item/extra_item2 对应
  芯片/声码1/声码2 组件；类别 = items.group（对齐 Plan 大类）；行内编辑
- **汇率设置**：按月录美元（或其它币）汇率，报表与出库折算取当月值
