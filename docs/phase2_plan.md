| #  | 决策 |
|----|------|
| D12 | 关账锁定与对账单同包交付 |

## 1. 定位

月度结算流水线：

```
日常录入 → 月末对账(销售×财务) → 关账锁定 → 备份归档
```

系统边界（过渡期）：**Excel = 生产计划工具；CuteERP = 台账与对账系统**。

## 2. 交付物与顺序

### 2.1 按月导出工作簿（先做，Excel 侧无缝衔接）
- `caxlsx` 生成月度工作簿，sheet 对齐现用 Excel 四表：
  1. 客户订单：接收日期/客户/订单号/通用型号/版本/数量/含税单价/要求交期/特殊要求
  2. 生产订单-六联单：六联单号/下单日期/客户/产品/数量/含税单价/版本/约定发货日期/发货数量 + 分配对（订单N/分配量N，来自分配台账）
  3. 出库单：日期/客户/六联单号/产品/数量/快递号
  4. 价格：现行价格表 + 最新阶梯批次
- 入口：工具菜单"导出当月"，可选任意月份

### 2.2 导入（幂等 + 校验报告）
- 客户订单导入：自然键（订单号 + generic_part_no + version）upsert，重复导入不产生重复数据
- 生产订单导入：解析 `订单N/分配量N` 列 → 直接生成 production_lines + production_allocations 台账记录
- 校验报告（每次导入必出，差异只报告不自动修）：
  - Σ分配量 = 六联单数量
  - 引用的客户订单/行存在
  - 分配量 ≤ 该行未签发余额
- `imports` 表：kind / month / file / imported_by / 统计；导入记录带 `source=batch` 标记，区分手工录入

### 2.3 月度对账单（页面 + 导出）
- `MonthlyStatement` 查询对象：维度 = 客户 × 月份
  - **订单核对段**：订单号/行号、通用型号、数量、单价（本币）、金额（本币 + 折算 RMB）
  - **出货核对段**：出库日期、六联单号、快递号、数量、金额
  - 合计：本币与折算 RMB 双口径（统一经由 RevenueQuery，D9）
- 差异处理：关账前修改源单据重出对账单；关账后走冲销单（D1）

### 2.4 关账 + 备份归档
- `closed_periods` 表：month / closed_by / closed_at
- 关账后该月单据锁定：模型层校验拒绝 update/destroy；重开需管理员并留痕
- 关账动作自动触发归档：
  - `pg_dump` 全库压缩归档（文件名含关账月份，如 `cute_erp_closed_202610.sql.gz`）
  - 当月 Excel 工作簿一并归档
- 每日兜底 pg_dump（保留 30 天）；月度归档保留 ≥ 12 个月
- 恢复语义（D13）：灾难 = 整库恢复到归档点；账务纠错 = 冲销单/重开月份修单

## 3. 实现要点
- 备份：`rake cute_erp:backup:monthly / :daily` + systemd timer，零第三方依赖
- Excel：`caxlsx`；导出模板列序以现用 Excel 为准
- 关账校验：Order / ProductionOrder / Shipment 在保存/销毁前检查单据日期是否落在 closed_periods
- 对账口径：全部经由 RevenueQuery，与营业额数字严格一致

## 4. 交付顺序

```
2.1 按月导出（Excel 侧先续上）→ 2.2 导入（过渡期双轨）
→ 2.3 对账单 → 2.4 关账 + 备份归档
```

## 5. 验收标准（摘要）
- 导出：任意月份一键导出工作簿，四表字段与现用 Excel 一一对应
- 导入：同一文件重复导入不产生重复数据；含分配错误的文件导入后得到差异清单报告
- 对账：指定客户+月份的对账单（页面/导出）数量金额与源单据一致，金额双口径
- 关账：关账月单据不可改删；重开后可改；关账自动产生归档文件
- 恢复：归档文件可在空库上恢复出完整应用数据
